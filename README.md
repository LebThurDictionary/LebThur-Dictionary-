# Leb Thur (Ethur) Lexicographical Database

An open-source dictionary and comparative linguistic mapping project bridging Acholi (Southern Luo) and **Leb Thur (Ethur)**, spoken by the Jo'Abwor people of Abim District, Uganda.

## Project Overview
While Leb Thur shares deep historical and lexical roots with Acholi, it possesses distinct phonetic shifts, traditional terminology, and regional vocabulary influenced by its cultural heritage and geography. This database systematically documents, verifies, and corrects these mappings.

## Core Phonetic & Lexical Rules Applied
* **Verb Endings:** Standard Acholi `-to` verbs map to Leb Thur `-dho` (e.g., *cito* $\rightarrow$ *cidho*).
* **Consonant Shifts:** Terminal stops transition from `-k` to `-g` (e.g., *cok* $\rightarrow$ *cog*) and dental/palatal variations (*dog* $\rightarrow$ *dhog*).
* **Vowel Harmony:** Core vowels adapt to authentic local pronunciation (e.g., *cam* $\rightarrow$ *cem*).
* **Native Lexical Substitutions:** Replacement of general Northern Luo terms with authentic Jo'Abwor expressions (e.g., *doo* $\rightarrow$ *akwar*, *malong* $\rightarrow$ *nabor*, *rwot* $\rightarrow$ *rwoth*).

## File Structure
* `lebthur_dictionary_comprehensive.csv`: The main master dataset containing all verified headwords, English meanings, parts of speech, and dialectal notes.
